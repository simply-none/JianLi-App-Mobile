## 新增功能域落地清单
1. 建 `lib/features/<module>/`（models / repositories / providers / components 按需原子拆分，带中文注释）。
2. 需要数据表：按「drift 三大铁律」加表定义并注册，跑 build_runner，老用户写 onUpgrade 迁移。
